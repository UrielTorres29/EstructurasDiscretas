# Práctica 1: *Haskell, Git y GitHub*

---
## Objetivo

Conocer las características básicas del lenguaje de programación Haskell, realizar su instalación y la de sus herramientas y compararlo con otro lenguaje como Rust. Además, aprender los conceptos básicos de Git y GitHub y crear un repositorio para el curso.

---
## Tiempo requerido

El tiempo requerido para realizar esta práctica fue de aproximadamente 2 horas

---
## Comentarios y problemas durante la instalación

Durante la instalación de Haskell, Git y la creación del repositorio de GitHub no hubieron problemas, todo se hizo correctamente, además, las herramientas fueron bien verificadas.

Entonces, no fue necesario aplicar ninguna solución, pues no se presentaron mayores problemas en la instalación ni durante la creación del repositorio.
